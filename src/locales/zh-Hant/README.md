# 繁體中文詞典維護

語言代碼為 `zh-Hant`，選單顯示「繁體中文」。以臺灣介面用語為基底，對照臺灣出版品、亞洲人類圖學院及香港人類圖實務者的用語。繁體地區並沒有所有流派一致的唯一譯名；本專案的選詞、別稱與來源見[繁體術語對照表](../../../docs/术语对照表.zh-Hant.md)。

這是一套獨立維護的完整詞典，不在執行時轉換簡體中文，不處理使用者姓名、地點或計算物件。初稿用 OpenCC 1.4.2 轉換字形，接著調整專業術語與介面用詞；之後請直接校訂本目錄，不要重新從簡體版覆蓋。

| 檔案 | 維護內容 |
|---|---|
| `gates.json` | 64 個閘門的主題、說明、象限與諧波編號 |
| `lines.json` | 384 條人類圖爻線的主題與說明 |
| `hexagrams.json` | 64 卦名、總義與 384 條易經爻辭 |
| `channels.json` | 36 條通道的說明與能量類型 |
| `gene-keys.json` | 64 組基因天命關鍵詞與原始專案說明的翻譯 |
| `vocabulary.js` | 類型、權威、人生角色、中心、閘門、通道、迴路與四箭頭術語 |
| `engine-messages.json`、`engine-templates.json` | 其餘引擎文案與動態句型，英文鍵與 `source` 不翻譯 |
| `ui-*.json` | 分功能的介面詞典，共用文案只在 `ui-common.json` 維護 |
| `index.js` | 資源入口、語言辨識、日期與顯示格式 |
| `content.js` | 將本目錄資料交給共用查找程式，不疊加其他語言正文 |

角色標籤採「探究者／隱士／烈士／機會主義者／異端者／人生典範」。正文中的一般研究、實驗、榜樣等敘述不必全改成角色名稱。閘門名稱仍翻譯上游的 Human Design 名稱，易經卦名獨立維護；基因天命頻譜保留英文對照，不加括號或額外分類前綴。

驗證：`node --test tests/i18n.test.js tests/localization.test.js tests/traditional-chinese.test.js`。測試驗證完整性、佔位符、來源鍵、地區術語與資料不變性，不能取代語義校對。新增功能依[本地化介面說明](../../../docs/localization.md)補齊三種語言，勿在頁面增加語言分支。
