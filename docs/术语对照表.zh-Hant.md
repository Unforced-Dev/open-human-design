# 繁體中文術語對照與選詞紀錄

查核日期：2026-09-24。語言代碼：`zh-Hant`。原始內容：專案使用的 `natalengine@1.6.0`。

本版以臺灣介面習慣為基底，對照臺灣出版資料及香港實務者的用詞。表中的「採用」是本專案為一致性作出的選擇，不宣稱是繁體中文圈唯一通行或官方統一譯名。簡體版保留原先的選詞；兩版共享原始英文識別碼，不因譯名差異改變計算。

## 維護邊界

上列資料用於核對術語，不用來替換上游解釋、增補信念主張或改動計算。未能證明跨流派一致的詞，仍以忠實翻譯專案英文、版內一致為原則；不能把以下完整對照表理解成每一項都獲得來源的統一背書。

初稿使用 OpenCC 1.4.2 轉換字形，之後分開處理領域術語及介面詞，修正如「箇中心」等轉換問題。執行時不依賴 OpenCC，也不掃描或改寫使用者姓名與地點。所有正式譯文只在 `src/locales/zh-Hant/` 對應檔案維護，不從簡體版覆蓋；查找演算法由 `chinese-readings.js` 共用。
